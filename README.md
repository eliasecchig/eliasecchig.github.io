# eliasecchig.github.io

Source of https://eliasecchig.github.io, built with Astro and deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml`.

Each post is a folder in `src/content/blog/` with `index.md` and its images beside it.

The design (tokens, prose and code styles) is adapted from the agents-cli docs site, Apache 2.0. See the license headers in `src/styles/global.css`, `src/code-theme.mjs` and `src/scripts/site.ts`.
